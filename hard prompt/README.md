# Steampunk Dwarf — Blender project

Полноценная low-poly модель стимпанк-гнома, собранная в Blender 5.2 по брифу из `hardchar.md`.

## Файлы

- `steampunk_dwarf.blend` — готовая сцена (персонаж, свет, камера, студийный пол).
- `renders/front.png`, `back.png`, `left.png`, `right.png` — контрольные ракурсы 1000×1000.
- `renders/three_quarter.png`, `renders/face.png` — дополнительный ракурс и крупный план лица.
- `renders/hero_front.png` — фронтальный рендер 1200×1200.
- `renders/turnaround_contact_sheet.jpg` — общий лист с шестью ракурсами.
- `renders/working/` — рабочие итерации и отдельные проверочные рендеры.

## Параметры модели

- Рост: **1.304 м**, размах рук: **1.521 м**, глубина: **0.426 м**.
- **15 472 треугольника**, 8 406 вершин.
- 11 объектов персонажа в отдельной коллекции **`Steampunk_Dwarf`**.
- Строгая T-поза, стопы на уровне пола (`z = 0`), взгляд вперёд (лицом к `−Y`).
- Все основные объекты UV-развёрнуты (Smart UV Project).
- Материалы Principled BSDF с крупными процедурными пятнами, шумом и полосами: кожа, ткань, медь, латунь, сталь, кожа головы. Без фототекстур и без subdivision.
- Мягкий трёхточечный свет (key/fill/rim, area-лампы), EEVEE, AgX, 48 сэмплов.
- Камера `Camera_Character`, 65 мм, выставлена на фронтальный ракурс.

## Объекты

- `DWARF_Body` — голова, шея, нос, щёки, предплечья и кисти с пятью пальцами.
- `DWARF_Eyes` — белки, радужки, зрачки, веки.
- `DWARF_Beard` — борода из крупных прядей, усы, брови, боковые латунные кольца и центральная обойма.
- `DWARF_Hat` — кожаная шапка авиатора с панелями, швами и боковыми клапанами.
- `DWARF_Goggles` — восьмигранные латунные оправы, линзы, перемычка, крепления и ремень.
- `DWARF_Shirt` — бежевая рубашка с закатанными рукавами и складками.
- `DWARF_Vest` — жилет, пуговицы, карман, часы с цепочкой, шестерёнка, задний ремень с пряжкой.
- `DWARF_Belt` — широкий ремень, пряжка, петля, хвост с отверстиями, заклёпки.
- `DWARF_Pants` — штаны со складками, манжетами и задними карманами.
- `DWARF_Boots` — массивные ботинки с латунными накладками, заклёпками и двумя ремешками.
- `DWARF_PouchTools` — правый подсумок, левый открытый карман и три гаечных ключа.

Коллекция **`DWARF_Environment`** содержит камеру, три источника света и студийный пол.

## Открытие

Открыть `steampunk_dwarf.blend` — сцена уже настроена, камера стоит на фронтальном ракурсе. Для проверки можно вращать `Camera_Character` вокруг персонажа или рендерить `F12`.
